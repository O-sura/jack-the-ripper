# Image credits

All images below are **CC0 / Public Domain Mark**, retrieved via the
[Openverse](https://openverse.org) API. CC0 and PDM impose no attribution requirement;
these credits are recorded as good practice and so the sources can be re-checked.

## Jack's portrait

`jack_profile.jpg` is **AI-generated** — a StyleGAN synthetic face from
[thispersondoesnotexist.com](https://thispersondoesnotexist.com). It is not a photograph
of any real human being.

That is deliberate and it matters: using a real person's face to stand in for a fictional
target in a hacking exercise would be exactly the problem this lab exists to teach about.
The source watermark was cropped out and all metadata stripped on re-save.

No other image below contains an identifiable person presented as "Jack Ripsley".
